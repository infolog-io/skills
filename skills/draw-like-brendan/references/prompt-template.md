# Render prompt template

```text
Primary request: [single visual proposition or short sequence]
Reference roles: [Sxx = composition]; [Sxx = object construction]; [Sxx = palette]; [LETTERING = lettering]. Inspect these originals before composing.
Format: [one sign/poster | one relationship with up to three objects | two-to-five loose beats]
Required content: [only essentials]
Text (verbatim): [short phrases]
Palette/background: derive from [named source]
Constraints: inherit source scale, empty space, glyph anatomy, naive object construction, and hard flat color. No previous generated image as style authority. Do not turn complexity into a dashboard or icon library.
```

Keep the prompt below 180 words. The individual attached originals carry more style information than a prose rule stack.
