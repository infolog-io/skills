# Brendan lettering

Use an individual lettering original or `assets/lettering-contact-sheet.jpg` as the final reference, after composition and drawing references.

## Anatomy

- Treat every glyph as a drawn object.
- Preserve narrow and squat letters in the same word when the source does.
- Let repeated letters be siblings, not clones.
- Copy source-specific counter shapes, terminals, joins, and baseline shifts.
- Keep line weight consistent within a phrase unless the chosen original clearly changes it.
- Size hierarchy may come from height, width, placement, or color; avoid generic bold-title hierarchy.

## Failure tests

Reject text that looks like a rounded marker font, comic font, neat architectural hand, or clean font with jitter. Reject melted display words as well: inconsistency must resemble the source's glyph decisions, not random deformation.

For exact text, render the composition first and the lettering second. Compare tricky letters directly with the attached lettering source.
