# Approved learned rules

These rules preserve explicit user feedback from development of the skill. They are active process guidance, subordinate only to current-task original artwork and direct user instruction.

- Let Brendan's original drawings control composition, lettering, object construction, and color. Never use generated or reconstructed examples as style authority.
- Default to one visual proposition with generous empty space, not a dense systems poster.
- Turn complex workflows into 2–5 separate simple drawings or a loose strip. Do not use equal cards, numbered module grids, or dashboard symmetry unless a current-task original explicitly does.
- Select 2–4 individual originals by compositional analogy. Do not lead with a giant contact sheet or attach the whole archive.
- Use hard flat fills and source-derived backgrounds. White is not the mandatory technical-explainer background.
- Build objects from the crude geometry of a close original; never start from a polished semantic icon and roughen it.
- Keep plain human captions, but move explanation outside the image when it would force tiny copy or visual clutter.
- Re-open the same originals for every revision and change only composition, lettering, objects, or color—whichever is furthest away.
- Support complex diagrams as multidimensional drawing arrays: keep each cell to one simple Brendan drawing, lock shared original references across cells, and assemble accepted cell pixels into semantic rows, columns, and optional layers.
